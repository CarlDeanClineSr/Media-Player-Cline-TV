# CLINE TV — CHANNEL LIBRARY MAP

This file is intentionally small.

The actual editable on-air programming is kept in the seven channel library files below. There is no second copy of the catalog in this file.

| Channel | On-air programming | Editable source |
|---:|---|---|
| 1 | TV CLASSICS | `01-tv-classics.md` |

| 5 | RADIO | `05-radio.md` |
| 6 | SPORTS | `06-sports.md` |
| 7 | TV SERIES | `07-tv-series.md` |

## Editing rule

Add, remove, or correct a program in the appropriate seven-file library.

Each program remains one simple Markdown line:

`- Program Title — https://archive.org/...`

The player reads these files directly at startup.

## Recovery

Programs recovered from earlier builds are kept in the appropriate library file. Deliberately held material is stored separately in `CONTENT_REVIEW_HOLD.md`.

Do not create another duplicate catalog here.
