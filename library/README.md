# CLINE TV ARCHIVE LIBRARY

The library is the staging area for the rebuilt Cline TV. The seven channel names follow the archived programming plan. The player is not being forced to consume the whole library yet; this keeps the library expandable while more Archive.org links are collected.

## Channel plan

1. **TV CLASSICS** — Star Trek, Space/UFO, classic horror, Dragnet/Hitchcock, Outer Limits, classic TV, In Search Of / Kaiju.
2. **MOVIES** — movie vault, Star Wars, monster-drive-in material.
3. **FAMILY & CARTOONS** — cartoons, Schoolhouse Rock, Rocky & Bullwinkle, Reading Rainbow and family material.
4. **DOCUMENTARIES · NOVA / COSMOS / SCIENCE** — science documentaries, NOVA, Cosmos, Connections, NASA/space, education and related documentary material.
5. **RADIO** — X Minus One, old-time radio, Churchill/broadcasts, jazz/music and related audio.
6. **SPORTS** — racing, Wide World of Sports and other sports material.
7. **TV SERIES** — the preserved sci-fi and television series material.

## Recovered so far

- **5,469** direct media links resolved from the archived V188 catalog.
- **291** additional direct media links recovered from the old ARCHIVE_LINKS ledger that were not in that catalog.
- **20** additional direct media links recovered from older catalog/harvest backups.
- The additions files are kept separately so they can be reviewed and assigned without losing anything.
- There are **311** unique URLs in the two additions files themselves; some may overlap each other because they were recovered from separate backup sources.

## NOVA

The archived NOVA collection is no longer represented by the small 22-item science list that was initially loaded into the new player. The old catalog contains **1,068 NOVA entries in Channel 24 alone**, and those are now included in the **DOCUMENTARIES · NOVA / COSMOS / SCIENCE** library section, along with the other documentary/science material.

## Library expansion

This is a growing source library. More Archive.org links can be added later without rebuilding the player structure each time.
